# Caesar Cipher

## Description

A Python implementation of the Caesar Cipher, one of the oldest and simplest encryption techniques. This program allows users to encrypt and decrypt messages using a user-defined shift value while preserving uppercase letters, lowercase letters, spaces, numbers, and special characters.

---

## Features

- Encrypts text using the Caesar Cipher algorithm
- Decrypts encrypted text back to the original message
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and special characters
- User-defined shift value
- Simple command-line interface

---

## Technologies Used

- Python

---

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vaneezaetp/caesar-cipher.git
```

2. Navigate to the project folder:

```bash
cd caesar-cipher
```

3. Run the program:

```bash
python ency&decry.py
```
